# Values

A session is never worse for having cogmer installed. It is never broken, slowed,
made noisy, robbed of context, or made to take a turn it was not asked to take. When
cogmer fails, the user loses collaboration and nothing else.

A component that gives up privacy or decentralization is justified only by a benefit
to the user it affects, never by a benefit to the maintainer, and the user is told
that it exists.
