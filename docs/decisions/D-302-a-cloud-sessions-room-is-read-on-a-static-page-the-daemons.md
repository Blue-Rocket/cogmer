# D-302 — A cloud session's room is read on a static page, the daemon's own view served from GitHub Pages

**Date:** 2026-11-25 · **Status:** active · **Areas:** view, trust, release

**Decision.** The page that reads a cloud session's room through the port of D-301 (a cloud session's daemon serves its room on a second overlay port, in lines, with a token made from the cloud key) is the daemon's own view, `cmd/cogmer/ui.html`, with `web/view/viewer.js` added at the place the view marks. `scripts/build-view.sh` builds it with tailcat's browser build, and `scripts/publish-view.sh` publishes it to the `pages` branch of `Blue-Rocket/cogmer`, which GitHub Pages serves at `https://blue-rocket.github.io/cogmer/view/`. The page polls the room every three seconds in place of the view's streams, which is an exception to D-289 (every page of the view lists every room in a pane beside the room it shows) for the pane's stream, and draws that pane from the list of rooms it polls, which carries what the stream carries, ends a connection whose request gets no answer in 10 seconds, and says the session is asleep when the next dial takes more than 15 seconds. It carries a security policy of its own as a meta tag, from `web/view/policy.txt`, because the daemon cannot send one for a page it does not serve: it loads no image but one made from bytes fetched through the daemon and allows a connection only to its own files, `tailcat.dev` for the list of relays and a WebSocket (D-212, the room page's security policy allows only the daemon's own images and requests). This is an exception to D-212: the page reaches the daemon only through a relay, so it may contact the relay list and a relay, and it still loads no image from an address. A room in the page's pane links to the same page with the room in the link's fragment, in place of the address of its own page that D-289 gives it in the daemon's view (D-077, every room has its own address in the view), since a static host has no page for each room, which makes the static page an exception to D-077 as well. The host of the page is a fourth centralized component, beside the relay, the model provider and the version check, and D-115 (a centralized component must trace to a disclosed tradeoff that benefits the person) says to revisit when one is proposed, which this decision does by passing that decision's three tests: this decision says what is given up, which is that the host sees the user's network address and supplies the script that reads the token, `plugin/README.md` tells the user so, and the gain is the user's, who can read the room from a phone.

**Rejected.**
- *A gateway or a hosted machine that serves the page and carries the room.* It puts a component somebody else operates between the user and the room, and its host has to be allowed in the cloud environment. The host of a static page carries no part of the room and receives neither the token nor the daemon's address, which are in the link's fragment.
- *A mod that draws the room.* A cloud session draws nothing, and the mobile app shows a mod only in the terminal on the user's own machine (Anthropic's page on mods, read on 2026-11-18, `d5140d4`).
- *A hook's `systemMessage` or a file in the session's outputs folder.* Neither Desktop nor the mobile app showed either, at a prompt sent from the phone as well (`a6cffcc`).

**Limits.** The host of the page serves the script that reads the token, so that host has to be trusted. A first visit downloads a 27 MB module, which GitHub Pages serves gzipped as 6.5 MB (`a9c20b1`), and no run has measured it over a phone's connection. The policy allows a WebSocket connection to any host, since the relays come from the list the page fetches and cannot be named in it, so a script that ran in the page could contact any host that way. That is the exposure D-212 closes for images and requests and leaves open for a WebSocket here, since a relay cannot be named in the policy, and the script is the page's own, from a host the user trusts. tailcat's README calls its browser demo experimental.

**Revisit when** Anthropic draws mods for a cloud session, or tailcat's browser build changes how it reaches a relay.
