# D-287 — A user with a computer of their own can also have a machine hosted

**Date:** 2026-11-20 · **Status:** not built · **Areas:** identity, hosts, project, trust

**Decision.** Any user can add a hosted machine (D-285, a user with no computer of their own has a machine hosted for them) beside the machines they run themselves, on the same terms and with the same disclosures to the user and to colleagues. A user's cloud sessions take the user's lists only from one of the user's machines (D-245, a cloud session takes its user's lists only from one of the user's machines), and a laptop is often asleep, shut or away, so a hosted machine answers those sessions and keeps the user's rooms' turns while the laptop is. That is the benefit to the user that D-115 (a centralized component must trace to a disclosed tradeoff that benefits the person) asks for.

**Rejected.**
- *Hosting only for a user with no computer of their own.* A user whose only computer is a laptop would have no machine to answer a cloud session started while the laptop is shut.

**Revisit when** a cloud session can take the user's lists from somewhere other than one of the user's machines.
