  Routes the pages describe, with who can use each, whether it can carry a file that differs between users, and
  whether the page says it reaches a Cowork cloud task:
    Upload a plugin (a folder, a .zip or a .plugin file) in claude.ai, Customize, Plugins, Add: any member, per
      account. It carries the user's own file, so it can differ between users. The pages say an upload is installed
      only for that member and is not distributed to the organization. Whether it reaches a cloud task: not stated
      on these pages.
    Add a marketplace by a GitHub owner/repo or a Git repository URL, in the same place: a member, unless an owner
      restricts it. It carries whatever the repository holds, so it differs between users only when the repository
      does. Reaching a cloud task: not stated on these pages.
    Add from Anthropic's catalog or directory (Discover, then Add): a member, with an owner choosing the sources on
      Team and Enterprise. The same catalog for everyone.
    Share (the three-dot menu, then Share), on Team and Enterprise after an owner turns sharing on: a member. "Sharing
      creates a link that opens the item for anyone it's shared with." The link opens the plugin for people it was
      shared with, who get the sharer's version, and each recipient turns it on. The same files for every recipient.
    Publish to org: a member submits and an owner reviews where review is required. The same approved files for
      everyone. No link is described.
    Organization routes: an owner or primary owner uploads ZIP files to an organization marketplace, or syncs one from
      GitHub, or from GitLab (beta); the page says "Claude Code cloud sessions don't support GitLab repositories yet".
      The same files for everyone. The Plugins API, with an admin key, sets availability by organization or by group
      ("required", "auto_install", "available", "not_available"), so which plugins a member has can differ by group
      while each plugin's files are the same.
    Claude Code: `claude plugin marketplace add --claudeai <name>` adds a marketplace that claude.ai holds, and the
      page for Claude Code says plugins "in your claude.ai account" are available in cloud sessions, which plugins
      installed on a computer at user or local scope are not. The Cowork page says plugins "download when the
      session starts".
  What the pages say none of: a link or a deep link that adds a marketplace or installs a plugin; a plugin declaring
  options (userConfig, "configure" or "settings") that a person is asked for at install; any route other than the
  account's own that reaches a cloud task.
