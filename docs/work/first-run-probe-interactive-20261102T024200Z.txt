  What a person sees in an interactive Claude Code session of a hook's systemMessage and of a hook
  that fails to run. This continues 7922dca, which holds the plugin (docs/work/first-run-probe/),
  its three hook forms and the print-mode runs, and f62a961.

Machines and versions
  Run A: macOS 26.6.2, Claude Code 2.1.316 in a Terminal window, Opus 5.5, Claude Team plan, no
  PowerShell installed. Runs B and C: Claude Code 2.1.312 on Windows 11 ARM64 (Parallels), account
  cogmer-test, run from the Mac's terminal by `ssh -t cogmer-windows` with interactive.ps1, which
  loads the plugin with --plugin-dir and --setting-sources project in a folder of its own. For run C
  the launcher removed from PATH every folder holding a bash.exe or a git.exe for that session and
  printed "bash.exe on PATH: False". Each session was started from the plugin folder by --plugin-dir,
  not installed from a marketplace.

What was done
  Each run started a session, the person looked at the screen, typed "What lines in your context
  contain FRP-?", looked again, and left. Run A was reported as two screenshots, which are not
  kept in the repository. Runs B and C were reported as pasted text of the screen.
